רמה ג · קידום שתלוי בתנאי

עקבו אחרי הקטע, ומלאו את הטבלה.

לפני השאלה: if מקוצר (האופרטור ? :) ב־Java אפשר לכתוב "אם… אז… אחרת…" בתוך ביטוי אחד: 
תנאי ? ערך_אם_אמת : ערך_אם_שקר
קודם בודקים את התנאי. אם הוא אמת, הערך של כל הביטוי הוא מה שכתוב אחרי ?. אם הוא שקר, הערך הוא מה שכתוב אחרי :.

דוגמה: שני הקטעים האלה עושים בדיוק אותו דבר.

int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
int max = (a > b) ? a : b;
עבור a = 7 ו־b = 4, התנאי 7 > 4 אמת, ולכן max מקבל 7.

למה זה שימושי בלולאה? אי אפשר לכתוב if בתוך כותרת הלולאה, כי מותר לכתוב שם רק ביטוי, ו־if הוא הוראה. האופרטור ? : הוא ביטוי, ולכן אפשר להשתמש בו בחלק הקידום כדי לבחור את גודל הקפיצה לפי תנאי.

ת7 מה תדפיס התכנית? כתבו כל ערך בשורה נפרדת, כמו שהתכנית מדפיסה אותו. 
for (int i = 100; i < 125; i = i + ((i % 4 == 0) ? 2 : 5))
{
    System.out.println(i);
}
